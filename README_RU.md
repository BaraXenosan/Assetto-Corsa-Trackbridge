# AC TrackBridge 0.2 — экспериментальный инструмент подготовки трасс

## Диагностика установленной игры

`node inspect-game.js --paks "ПУТЬ_К_Paks" --out game-inspection.json`

Инспектор читает только заголовки контейнеров IoStore версий 1–5, проверяет наличие частей UCAS и сохраняет список PAK. Исходные файлы не изменяет; существующий отчёт не перезаписывает. Версию Unreal по версии контейнера не определяет. Шифрование отмечается по флагу заголовка; извлечение ассетов и проверка их целостности не выполняются. Код завершения 2 означает ошибки контейнеров/отсутствующие части, 1 — ошибку запуска.

Проверка: `node tests/inspect_test.js`. Описание заголовка сверено с [CUE4Parse](https://github.com/FabianFG/CUE4Parse/blob/master/CUE4Parse/UE4/IO/Objects/FIoStoreTocHeader.cs).

Локальная проверка 19.09.2026: 39 контейнеров, 35 с флагом шифрования, все заявленные части найдены. Результат — `game-inspection.json`. Следующий этап требует извлечения ресурсов выбранной трассы и исследования её игровых структур.

**Не создаёт готовую трассу для F1 Manager 24.** Это рабочий прототип чтения и экспорта исходных ресурсов Assetto Corsa. Адаптер формата гоночных данных F1M24, сборка уровня и игровая проверка ещё не реализованы.

## Запуск

1. Распакуйте весь ZIP.
2. Откройте **TrackBridge.html** в актуальном Chrome или Edge на компьютере. Интернет, Python, Node.js, сервер и установка приложения не нужны.
3. Нажмите «Папка трассы» и выберите `assettocorsa/content/tracks/название`.
4. Выберите нужный `models.ini` / `models_конфигурация.ini`. Проверьте галочки моделей и нажмите «Прочитать выбранные модели».
5. Проверьте каркас сверху и в объёме. Затем нажмите «Скачать пакет подготовки ZIP».

Альтернативный запуск для разработки: index.html рядом с core.js и app.js. TrackBridge.html содержит core.js, project.js и app.js внутри одного файла.

Для проверки без игры в demo находится созданный нами синтетический KN5: один прямоугольник, материал и два AI-узла. Это тест формата, а не настоящая трасса.

## Что реализовано

- Статические KN5 v5/v6: иерархия, родительские матрицы, позиции, нормали, UV, треугольники, материалы, исходные текстуры.
- models.ini: выбор моделей и смещение POSITION, отдельные конфигурации. Ненулевые ROTATION явно отклоняются.
- Проверка отсутствующих моделей в конфигурации до экспорта; автоматический выбор models_gp_2024.ini при его наличии.
- Чтение метаданных ui_track.json, DRS-зон, поверхностей, стартовых/пит-позиций и пар AC_TIME. Это исходные данные AC, а не правила F1M24.
- Отдельный collision.obj для активных физических мешей с числовыми префиксами. Он сохраняет в том числе невидимую дорожную геометрию. Это ещё не cooked-коллизия Unreal.
- Каркасный поворачиваемый просмотр с фокусом на трассе по AI-линии; зелёный цвет для имён ROAD/ASPH/KERB/CURB; AI-линии розовым, пит-линии жёлтым.
- OBJ/MTL, текстуры в исходном формате, JSON с параметрами AC-материалов и именованными узлами.
- Экспериментальное чтение базовых координат AI v7: только точки из fast_lane.ai / pit_lane.ai. Остальные данные не интерпретируются. Линии не замыкаются автоматически.
- Преобразование X,Y,Z AC в X,Z,Y, масштабирование (100 по умолчанию), поворот вокруг вертикальной оси.
- Снимок вида сверху PNG и JSON-отчёт экспорта.
- Обнаружение повреждённых файлов; при ошибке выбранной модели экспорт всего пакета блокируется, чтобы не выдавать неполную трассу за готовую.

## Содержимое экспортируемого ZIP

- models/.../collision.obj — кандидаты физических поверхностей; для импорта настройте их как невидимую коллизию, не накладывайте их как видимые объекты.
- models/.../model.obj и model.mtl — геометрия и приблизительный diffuse-материал.
- models/.../textures/ — исходные байты текстур, обычно DDS. Поддержка DDS зависит от импортёра; приложение не переводит DDS в PNG.
- models/.../materials.json — имена шейдеров, параметры, текстурные слоты.
- models/.../anchors.json — узлы AC_START, AC_PIT и другие, если они есть. Матрицы sourceMatrix остаются исходными, position уже преобразован.
- lines/*.csv — координаты линии в выбранном масштабе и source_distance_m в исходных метрах.
- trackbridge-project.json — параметры, источники, список мешей, замечания и незавершённые шаги. Повторный импорт этого отчёта приложением пока не реализован.

## Что требуется для реального переноса в F1M24

Необходимо исследовать конкретную трассу F1M24: её пакеты уровня, игровые классы, траектории, пит-лейн, сектора и ссылки на связанные данные. Затем написать и проверить адаптер, создать материалы и коллизию, собрать ресурсы совместимым инструментарием и провести тест в игре. В этой версии таких возможностей нет. Переименование OBJ или упаковка его в PAK не решает задачу.

Для следующего этапа нужны реальная папка трассы AC (KN5 + models.ini + ai) и полный набор извлечённых ресурсов одной целевой трассы F1M24 с зависимостями. Один произвольный .umap не гарантирует достаточность данных. Точная версия и способ cooking не предполагаются без проверки игры.

## Ограничения

- Нет обхода защиты CSP, skinned mesh, нестандартных расширений или переноса CSP-эффектов.
- Не воспроизводит освещение и AC-шейдеры. OBJ не хранит игровые LOD/коллизию; сведения о LOD остаются в отчёте.
- Скрытые меши пропускаются в model.obj, если не включена соответствующая галочка. Физические меши могут отдельно попасть в collision.obj; его экспорт включён по умолчанию. Активные LOD не объединяются автоматически — возможны перекрывающиеся модели.
- Суммарный вход KN5 ограничен 512 МБ; 12 млн вершин на модель; ZIP ограничен 768 МБ. Браузеру потребуется существенно больше оперативной памяти. Экспорт большой модели может временно задержать интерфейс.
- Каркас предпросмотра прорежен до примерно 40 тысяч треугольников, экспорт не прорежен. PNG — диагностический снимок, не игровая миникарта.
- При ручном выборе без models.ini модели имеют нулевое внешнее смещение. AI-линии из нескольких конфигураций могут накладываться: предпочтителен выбор конкретного models_*.ini.
- У программы нет доступа к установленной игре. Исходники и папка Paks не изменяются.

## Проверки на реальной Kalinago v0.9.2

- Прочитаны все 39 KN5 в пользовательском архиве.
- Полностью экспортирована конфигурация gp_2024: 23 модели; 2 572 956 исходных треугольников.
- 22 полученных OBJ проверены независимым скриптом: конечность координат, допустимость индексов, соответствие количества граней. Проверено 2 653 511 граней с учётом отдельных визуальных и физических экспортов; некоторые физические меши также видимы, поэтому их нельзя суммировать как уникальные исходные грани.
- Найдены 36 стартовых позиций, 36 пит-позиций, 3 пары тайминга, 2 зоны DRS, 19 поверхностей.
- Гоночная линия: 3612 точек; пит-линия: 579 точек.
- В gp_2013 отсутствует kunos_props.kn5. Эта конфигурация правильно блокируется, файл не подменяется другим.
- Проверка интерфейса в Chromium 153: загрузка реальной папки Kalinago, выбор gp_2024, все 23 модели, 4191 точка двух AI-линий, скачивание JSON и полного ZIP, блокировка неполной gp_2013. Ошибок JavaScript не обнаружено. Все 300 файлов браузерного ZIP прошли проверку CRC.
- 16 проверок ядра и 7 проверок проекта: `node tests/test.js` и `node tests/project_test.js`.

В папке kalinago_validation — результаты проверки, исходные координаты линий в преобразованном виде и отчёт. Полная геометрия и текстуры трассы повторно в архив приложения не включены.

## Последовательный экспорт больших трасс

Дополнительный convert.js обрабатывает модели по одной и пишет OBJ блоками. Нужен Node.js 18+; браузерная версия установки Node.js не требует.

```bat
node convert.js --track "D:\Steam\steamapps\common\assettocorsa\content\tracks\00_kalinago" --layout models_gp_2024.ini --out "D:\Kalinago_Preparation"
```

Папка результата должна быть новой. При сбое незавершённые файлы остаются в папке `.partial`; для повторного запуска задайте новое имя или удалите эту конкретную временную папку самостоятельно. Опции: `--report-only` (без моделей и текстур, но с CSV), `--no-textures`, `--scale 100`, `--yaw 0`.

Выход CLI — такой же промежуточный набор, не готовый мод. Исходные markers/timingGates и статистика линий в JSON остаются в метрах AC. transformedMarkers и CSV используют выбранное преобразование.

F1 Manager 2024 недоступен для запуска: игровых испытаний и создания PAK нет. Полный набор игровых ресурсов целевой трассы отсутствует. Ранее переданный F1Manager24.zip проверен и содержит один EXE, а не ассеты трассы. Версия игры, из которой получен отдельный Lvl_Bahrain.umap, по самому имени файла не устанавливается.
