# Изолированный проект для UE 5.1

Проверен с установленным UE5.1.1 в `C:/Program Files/Epic Games/UE_5.1`: тест осей, импорт дорожного меша Kalinago и cooking выполнены. Тестовый IoStore независимо прочитан CUE4Parse с таблицей типов игры; 405449 треугольников сохранены. Полный отчёт: `../../research/kalinago-cooked-verification01.json`. Загрузка в игре ещё не проверена, `installable: false`.

Повторная проверка импорта:

```powershell
.\Run-ImportProbe.ps1 -EngineRoot 'C:\Program Files\Epic Games\UE_5.1'
```

Скрипт импортирует только маленький асимметричный тестовый OBJ в уникальный каталог `/Game/TrackBridge/Probes`. Он проверяет четыре треугольника и границы `[0,0,0]..[100,200,300]` см. Это позволяет обнаружить дополнительную смену осей/масштаба импортёром до массового импорта уже преобразованных моделей Kalinago. Отчёт находится в `Saved/TrackBridge`; существующие ассеты не заменяются.

Даже успешный тест подтверждает только геометрию импорта. Материалы, коллизии, cooking, совместимость cooked-данных со сборкой игры и загрузка нового уровня проверяются отдельно. Здесь нет кода установки мода, изменения игровых архивов или выставления installable=true.

`Run-CookPilot.ps1 -EngineRoot <UE_5.1> -PilotReport <успешный JSON импорта> -LogPath <новый лог>` выполняет cooking выбранного пилотного ассета. CookDir должен быть физическим каталогом: виртуальный путь может привести к успешному завершению без нужного ассета. Скрипт проверяет свежесть `.uasset/.uexp`. `Stage-CookedPilot.ps1` подготавливает отдельное дерево упаковки; повторное использование существующей выходной папки запрещено.

`prepare_textures.py` декодирует исходные текстуры в PNG с проверкой пикселей; `prepare-materials.js` сопоставляет им исходные слоты. Перенос AC-шейдеров в материалы Unreal остаётся отдельной работой.

`Content/Python/import_kalinago_scene.py` импортирует видимые модели и создаёт отдельный уровень с материалами base color/alpha. Успешный запуск: 18 моделей, 155 материалов, 111 текстур. `Run-CookScene.ps1 -EngineRoot <UE_5.1> -SceneReport <JSON импорта> -LogPath <новый лог>` готовит сцену с именованными свойствами и встроенным кодом шейдеров. Unversioned-схема стандартного UE5.1 Material не совпадает с runtime-usmap F1 Manager; для сцены `-Unversioned` не применять.

`Stage-CookedScene.ps1 -SceneReport <JSON импорта> -CookReport <лог cooking.json> -OutputDirectory <новая папка>` подготавливает 285 пакетов и исходную таблицу scriptobjects для retoc. Последняя проверенная упаковка: `../../research/kalinago-scene-pack02`; отчёт `../../research/kalinago-scene-verification01.json`. Проверены в том числе 155 material shader maps и 2093 записи кода. Сцена не содержит гоночного компонента и не является готовой заменой Bahrain.

## Карта для редактирования Kalinago — 25.09.2026
Открыть F1Manager24.uproject в UE 5.1. Стартовая карта: /Game/TrackBridge/Authoring/Kalinago_Editor.
Содержит исходные редактируемые меши/материалы Kalinago, 222 editor-only маркера трассы, старта, гаражей, пит-стопов, секторов и DRS, камеры предварительного просмотра и дневной свет редактора. Каталоги World Outliner: TrackBridge/*.
Content/TrackBridge/Authoring/anchors.json — исходная раскладка маркеров; после переноса нативных гаражей актуальные гаражные позиции находятся в research/kalinago-component-garages01.json, маркеры этой первой карты ещё требуется синхронизировать.
Kalinago_Minimap_Preview.png и minimap-mapping.json — предварительная миникарта с двумя DRS-зонами, ещё НЕ подключённая к игровому UI.
Важно: это рабочий редакторский проект, не полная реконструкция исходников F1 Manager. Нативные RaceSim классы и cooked Blueprint-анимации игры не превращены в редактируемые исходные Blueprints. Их интеграция выполняется отдельно через TrackWriter. Маркеры и preview-камеры editor-only и не исправляют игровые позиции автоматически.
Установлен дополнительный контейнер TrackBridge_Kalinago_1000_P с очисткой, гаражами, переносом основных камер и солнечным сдвигом. Чтение проверено; игровая валидация не завершена. Закрытые фасады гаражей Kalinago и полноценная привязка анимаций требуют дальнейшей работы.


Обновление 1002: гаражные маркеры синхронизированы с garage-layout02; створки скрыты отдельным материалом, в runtime-сцену добавлен слой обзорной карты. Проверка камер и анимаций в игре ещё требуется. См. RESEARCH_RU.md в корне проекта.
